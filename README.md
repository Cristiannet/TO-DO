## Funcionalidades

- Crear tareas, marcarlas como completadas y filtrarlas por día en el calendario.
- **Eliminar tareas** (Sprint 2 · Tarea 6): cada tarjeta tiene un botón "Eliminar" que llama a `TaskManager.deleteTask(taskId)`. El método quita la tarea de `this.tasks`, guarda en `localStorage` y la lista se vuelve a renderizar; al recargar la página la tarea no reaparece.
- Pomodoro, tema claro/oscuro y reproductor de Spotify.
